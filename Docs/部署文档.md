# Baka Community 部署文档

本文档说明如何从零部署 Baka Community（聊天服务器 + Web 前端），适用于 Ubuntu 22.04 / Debian 12 等 Linux 发行版。

- 后端：C++17，epoll 主从 Reactor（TCP binary）+ Boost.Asio/Beast（WebSocket），protobuf 协议
- 前端：Vite + Vue 3，构建产物由后端 WebSocket 模式静态提供
- 数据库：MySQL 8.0（必须 utf8mb4）
- 缓存：Redis（可选，`enabled=false` 时回退纯 MySQL）

---

## 1. 环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Linux | Ubuntu 22.04+ / Debian 12+ | 仅支持 Linux（epoll） |
| g++ | 支持 C++17 | build-essential |
| CMake | ≥ 3.10 | 构建系统 |
| Boost | ≥ 1.74 | 仅 `system` 组件 |
| Protobuf | 3.x | `libprotobuf-dev` + `protobuf-compiler` |
| MySQL | 8.0 | 服务端 + Connector/C++ |
| nlohmann-json | 3.x | `nlohmann-json3-dev` |
| Redis | 6+（可选） | 缓存，可关闭 |
| Node.js | ≥ 18 | 前端构建（Vite 6） |
| npm | 随 Node 附带 | 前端依赖 |

> Redis 客户端库 `hiredis` / `redis-plus-plus` 由 CMake `FetchContent` 在构建时从 GitHub 拉取并静态编译，**首次 configure 需要能访问 github.com**。

---

## 2. 安装系统依赖

```bash
sudo apt-get update
sudo apt-get install -y \
    build-essential cmake git \
    libboost-system-dev \
    libprotobuf-dev protobuf-compiler \
    libmysqlcppconn-dev \
    nlohmann-json3-dev \
    redis-server \
    mysql-server \
    nodejs npm

# 确认 Node 版本（Vite 6 需要 Node 18+）
node -v
npm -v
```

> 如果系统 Node 版本过低，可参考 NodeSource 安装新版：
> ```bash
> curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
> sudo apt-get install -y nodejs
> ```

## 3. 初始化 MySQL

### 3.1 创建数据库与账号

```bash
sudo mysql
```

在 MySQL 控制台执行：

```sql
-- 创建应用账号（与 configure.json 保持一致）
CREATE USER IF NOT EXISTS 'chat_server'@'localhost' IDENTIFIED BY 'Chat_123!';
GRANT ALL PRIVILEGES ON chat_server.* TO 'chat_server'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

### 3.2 建表

```bash
cd /path/to/server
mysql -u chat_server -p'Chat_123!' < sql/create_table.sql
```

`create_table.sql` 会：
- 创建数据库 `chat_server`（utf8mb4 / utf8mb4_0900_ai_ci）
- 创建 11 张表：`Account` / `account_email` / `friend_relation` / `relation_apply` / `Group` / `Groupmember` / `message` / `community` / `community_member` / `file` / `file_transfer`

> **从旧库升级**才需要按顺序执行 `sql/` 下的 alter 脚本（社区头像/背景、文件系统字段、主题默认值、自聊好友等）。全新部署只需 `create_table.sql`。

验证：

```bash
mysql -u chat_server -p'Chat_123!' -e "USE chat_server; SHOW TABLES;"
```

## 4. 创建文件存储目录

文件传输（头像、聊天附件等）落盘目录在 `configure.json` 的 `file_storage.root` 指定：

```bash
sudo mkdir -p /home/ubuntu/chat_server_files
sudo chown -R $(whoami):$(whoami) /home/ubuntu/chat_server_files
```

> 如果使用其它路径，记得同步修改 `configure.json` 中的 `file_storage.root`。

---

## 5. 配置

把仓库根目录的 `configure.json` 复制到运行目录（通常为 `build/`）：

```bash
cp configure.json build/
```

关键配置项（详细见 `readme.md` 与 `configure.json` 注释）：

| 配置 | 说明 |
|------|------|
| `net_layer` | `"websocket"`（浏览器 + WS）或 `"binary"`（纯 TCP）。二选一，改完重启 |
| `websocket.path` | WebSocket 路径，默认 `/ws` |
| `websocket.web_root` | 前端静态资源目录。从 `build/` 运行时填 `"../web"`，从根目录运行时填 `"./web"` |
| `database.*` | MySQL 连接信息与连接池上限 |
| `redis.enabled` | `true` 用缓存，`false` 回退纯 MySQL |
| `file_storage.root` | 文件落盘根目录 |
| `max_connections` | 最大并发连接数 |

> 程序启动时读取**当前工作目录**下的 `configure.json`，读不到则用默认值。

---

## 6. 构建后端

```bash
cd /path/to/server/build
cmake ..
cmake --build . -j$(nproc)
```

首次 `cmake ..` 会通过 FetchContent 拉取 `hiredis` / `redis-plus-plus`，需要联网；之后增量编译只需第二条命令。

产物：`build/server`

---

## 7. 构建前端

```bash
cd /path/to/server/frontend
npm install
npm run build
```

构建产物输出到 `../web`（即 `server/web/`），由后端 WebSocket 模式静态提供。

> 开发模式 `npm run dev` 会在 `5173` 端口起 Vite，并把 `/ws` 代理到后端 `8080`。

---

## 8. 启动

```bash
cd /path/to/server/build
./server
```

启动后应看到类似日志：

```
[ServerConfig] net_layer=websocket, use_heartbeat=..., ws_path=/ws, ws_io_threads=4, web_root=../web, max_connections=10000, db_conn_count=4
[MySQL_Conn_Pool] initialized 4/4 connections.
[RedisPool] connected to 127.0.0.1:6379, pool_size 4
[ws] WebSocket server listening on port 8080, path /ws, io_threads 4
```

浏览器访问 `http://<host>:8080/` 即可使用聊天界面。

## 9. 生产部署（systemd）

### 9.1 创建服务单元

`/etc/systemd/system/baka-server.service`：

```ini
[Unit]
Description=Baka Community Chat Server
After=network.target mysql.service redis-server.service
Wants=mysql.service redis-server.service

[Service]
Type=simple
# 工作目录必须包含 configure.json，且 web_root 指向前端产物
WorkingDirectory=/path/to/server/build
ExecStart=/path/to/server/build/server
Restart=always
RestartSec=3
User=ubuntu
LimitNOFILE=65535

[Install]
WantedBy=multi-user.target
```

启用并启动：

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now baka-server
sudo systemctl status baka-server
```

### 9.2 防火墙

放行 `8080` 端口（若使用 nginx 反代则只放行 80/443）：

```bash
sudo ufw allow 8080/tcp
```

### 9.3 可选：Nginx 反向代理 + HTTPS

```nginx
server {
    listen 80;
    server_name chat.example.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 86400;
    }
}
```

> WebSocket 需要正确的 `Upgrade` / `Connection` 头，否则浏览器连不上 `/ws`。

## 11. 常见问题

| 问题 | 原因 / 解决 |
|------|-------------|
| 首次 `cmake ..` 卡住或失败 | FetchContent 需要联网拉取 hiredis / redis-plus-plus；检查 github.com 连通性 |
| 启动后连不上数据库 | 检查 `configure.json` 的 `database.*`，确认库/账号/密码，确认 `sql/create_table.sql` 已执行 |
| 中文/emoji 乱码 | 数据库字符集必须是 utf8mb4 |
| 打开网页 404 或白屏 | `net_layer` 需为 `websocket`；`web_root` 需正确指向 `web/`；前端需先 `npm run build` |
| WS 握手失败 / 426 | 确认客户端连的是 `ws://host:8080/ws` 且 `net_layer=websocket` |
| binary 模式没有页面 | binary 模式不提供 HTTP 静态服务，属预期 |
| 文件上传失败 | 确认 `file_storage.root` 目录存在且进程有写权限 |
| 切协议后连不上 | `binary`/`websocket` 二选一，改完必须重启服务 |
