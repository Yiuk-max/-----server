# 架构模型与状态机（ASCII 图）

> 用 ASCII 图描述 Baka Community 的网络模型、业务模型、文件传输模型、
> Session 生命周期与各类状态机。当前实现为 C++17 / epoll 主从 Reactor + Boost.Asio WebSocket。

---

## 1. 网络模型

### 1.1 两种网络层二选一（同一端口 8080）

```
                    configure.json
                    net_layer = "binary" | "websocket"
                            │
            ┌───────────────┴───────────────┐
            ▼                               ▼
   ┌───────────────────┐          ┌────────────────────┐
   │ binary 网络层      │          │ websocket 网络层     │
   │ epoll 主从 Reactor │          │ Boost.Asio + Beast  │
   └─────────┬─────────┘          └─────────┬──────────┘
             │                              │
             └──────────────┬───────────────┘
                            ▼
               同一套业务层（client_session / handler / repo / file_service）
```

### 1.2 binary 模式：epoll 主从 Reactor

```
                    main_reactor（主线程）
                    accept 新连接，轮询分发给 sub_reactor
                              │
        ┌──────────┬──────────┼──────────┬──────────┐
        ▼          ▼          ▼          ▼          ▼
   sub_reactor sub_reactor sub_reactor ...   （每个有自己的 ThreadPool）
        │
        ▼
   connection（fd -> connection 映射）
        │  ┌────────────┐
        │  │ receiver    │  append_data / process_recv_data（粘包/半包解析）
        │  └────────────┘
        │  ┌────────────┐
        │  │ sender      │  add_to_out_buffer / send_msg（非阻塞写 + epoll 写事件）
        │  └────────────┘
        ▼
   client_session（业务会话）
```

```
TCP 自定义帧：
┌──────────────┬──────────────┬──────────────────┬─────────────────┐
│ 4B total_len │ 4B payload_len│ protobuf 字节     │ 文件数据(可选)   │
└──────────────┴──────────────┴──────────────────┴─────────────────┘
```

### 1.3 websocket 模式：Asio + Beast

```
   Asio io_context（ws_io_threads 个线程跑 io_context）
        │
        ▼
   WsServer acceptor（监听 :8080）
        │ 新连接
        ▼
   WsSession（每个连接绑定独立 strand，串行读写）
        │
        ├─ 握手 / 静态文件 / WebSocket 帧
        ├─ on_read → decode_binary(payload, file_data)
        │
        ▼
   业务线程池（business_pool）
        │
        ▼
   client_session（业务会话）
        │ 处理完成后 post 回 strand
        ▼
   do_read（恢复下一次读，形成单连接背压）
```

```
WS binary 帧：
┌──────────────┬──────────────────┬─────────────────┐
│ 4B payload_len│ protobuf 字节     │ 文件数据(可选)   │
└──────────────┴──────────────────┴─────────────────┘
```

## 2. 业务模型

### 2.1 分层结构

```
                      client_session（每连接一个）
     ┌──────────────────────┼──────────────────────────┐
     │                      │                          │
     ▼                      ▼                          ▼
 handlers_ map        repo_hub_（RepositoryHub）    file_service_
 (type→handler)       accounts/emails/friends/      (FileService)
     │                groups/messages/communities/files
     ▼
 Message_handler::handle_message(msg, session, file_data)
     │
     ├─ Chat_handler     私聊/群聊/历史/好友
     ├─ Group_handler    群管理
     ├─ Community_handler 社区/频道
     ├─ File_handler     文件传输
     └─ Base_handler     登录/注册/头像/主题
```

### 2.2 消息分发流程

```
connection / WsSession 收到一帧
        │ payload + file_data
        ▼
client_session::on_message(payload, file_data)
        │ 1. online 校验
        │ 2. ParseFromString → Envelope
        │ 3. type == "heartbeat" → heartbeat_ack
        │ 4. handlers_[type]->handle_message(msg, *this, file_data)
        ▼
handler 调 session 的发送端口：
   package_message / package_chat_message / package_envelope /
   send_file_packet / send_serialized_packet
        │
        ▼
IClientTransport::send_packet / send_serialized
```

### 2.3 在线表与通知

```
session_manager（单例，UID -> client_session 在线表）
   ├─ replace_online(uid, session)    登录/顶号
   ├─ remove_online_if_same(uid, ptr) 断线清理（防迟到误删）
   ├─ find_session(uid) / find_sessions(uids)

NoticeService（单例，向在线用户发消息）
   ├─ send_to_user / send_to_users
   ├─ send_to_user_with_id / send_to_users_with_id
   └─ is_online(uid)
```

## 3. 文件传输模型

### 3.1 分层

```
File_handler（消息分发）
      │
      ▼
FileService（业务编排）
   │            │
   ▼            ▼
FileStorage   I_file_repo / file_repo
（磁盘流式）  （MySQL 元数据/会话）
      │
      └─ SendFn(Envelope, file_data) → IClientTransport
```

### 3.2 上传时序

```
Client                          Server
  │ file_upload_init              │ 校验大小 → 生成 storage_key
  │──────────────────────────────►│ 建 tmp writer + file_transfer(uploading)
  │ file_upload_ready             │
  │◄──────────────────────────────│
  │ file_chunk × N + file_data    │ write_at(offset) → 置 received 位图
  │──────────────────────────────►│ 更新 transferred/next_chunk_index
  │ file_upload_done              │
  │──────────────────────────────►│ 位图全齐？commit() → 重算 sha256
  │                               │ 写 file 行 → 回填 file_transfer.file_id
  │ file_upload_complete          │
  │◄──────────────────────────────│
```

### 3.3 下载时序（拉取式）

```
Client                          Server
  │ file_download_init(file_id)   │ 建 file_transfer(downloading)
  │──────────────────────────────►│
  │ file_download_ready           │
  │◄──────────────────────────────│
  │ file_download_chunk(0)        │ seek(0) → read → file_chunk
  │──────────────────────────────►│
  │ file_download_chunk(1)        │ seek(chunk) → file_chunk
  │──────────────────────────────►│
  │ ... 逐块拉取（背压）           │
  │ 最后一块完成后                 │ transfer = completed
```

### 3.4 断线重续（上传）

```
上传中发了几块 → 断线（writer 析构，tmp 保留）
      │
      ▼ 重连登录
  file_upload_resume(transfer_id)
      │
      ▼
Server: get_transfer → 恢复 storage_key/type/位图
        open_append(tmp) 重建 writer → file_upload_ready
      │
      ▼
Client: 从 next_chunk_index 继续发块 → file_upload_done → 完成
```

## 4. Session 生命周期

### 4.1 连接会话状态

```
                连接建立
                   │
                   ▼
          ┌─────────────────┐
          │   未登录 online  │  (logged_in_uid = -1)
          └────────┬────────┘
                   │ login / verify_token 成功
                   ▼
          ┌─────────────────┐
          │    已登录       │  (online=true, uid>=0, 有 account/social)
          └──┬───────┬─────┘
             │       │
   logout    │       │  exit_self / kick_offline / 断线
             ▼       ▼
       ┌─────────┐ ┌─────────────────────────┐
       │ 未登录   │ │ 断开（on_disconnected）  │
       │ (保留连接)│ │ online=false, uid=-1     │
       └─────────┘ └─────────────────────────┘
```

### 4.2 登录（顶号）流程

```
login 成功
   │
   ▼
activate_session(account, social, &old_session)
   │
   ├─ 旧 uid != 新 uid → remove_online_if_same(old, this)
   ├─ online 校验（断线则返回 false）
   ├─ 替换 current_account_ / social_manager_ / logged_in_uid_
   ├─ replace_online(uid, self) → 返回被顶掉的 old_session
   │
   ▼
old_session && old_session != this → old_session->kick_offline()
```

### 4.3 关闭策略（两种网络层通用）

```
CloseMode
   ├─ immediate              立即 shutdown/close，不再写
   └─ after_pending_writes   先等发送队列写完，再关

binary connection::close(mode)
   ├─ closed_ 幂等
   ├─ after_pending_writes && 发送队列非空 → closing_after_write_ = true，等 handle_write
   └─ 真正 close(fd) → finish_close → session->on_disconnected()

ws WsSession::close(mode)
   ├─ immediate → teardown()
   └─ after_pending_writes → 有写队列则 closing_after_write_ = true，写完再 do_close()
```

## 5. 状态机

### 5.1 文件传输会话状态机（file_transfer.status）

```
                 ┌──────────────┐
                 │  uploading   │◄──────────────┐
                 └──┬───┬───┬──┘               │
       全部块到齐    │   │   │ 暂停             │ 继续(resume)
      +hash通过     │   │   └─────────┐        │
                    ▼   │             ▼        │
              ┌───────────┐      ┌──────────────┐
              │ completed │      │    paused    │
              └───────────┘      └──────────────┘
                    ▲ cancel/超时/错误
                    │
        ┌───────────┼───────────┐
        ▼           ▼           ▼
   ┌──────────┐ ┌──────────┐ ┌──────────┐
   │cancelled │ │  failed  │ │  ...     │
   └──────────┘ └──────────┘ └──────────┘

                 ┌──────────────┐
                 │ downloading  │◄──────────────┐
                 └──┬───┬───┬──┘               │
       最后一块拉完  │   │   │ 暂停             │ 继续(resume)
                    ▼   │   └─────────┐        │
              ┌───────────┐      ┌──────────────┐
              │ completed │      │    paused    │
              └───────────┘      └──────────────┘
```

### 5.2 上传会话内部（FileService::UploadCtx）

```
uploading
   │ 收到 file_chunk：write_at(offset) → 置位图
   │ next_chunk_index = 第一个缺失块
   │
   ├─ 位图全齐 → upload_done → commit → completed
   ├─ pause → paused → resume → uploading
   ├─ cancel → writer->abort() → cancelled
   └─ 断线 → 内存 ctx 销毁（tmp 保留）
              │
              ▼ file_upload_resume
         重建 ctx（received 位图 + writer append）
```

### 5.3 下载会话（拉取式）

```
downloading
   │ 客户端逐块 file_download_chunk
   ├─ chunk_index 有效 → seek → read → file_chunk → 更新进度
   ├─ 最后一块 → completed
   ├─ pause → paused（客户端停止拉块）
   ├─ resume → downloading
   └─ cancel/超时 → cancelled/failed
```

### 5.4 分片接收位图（received_bitmap）

```
chunk_count = N，received = 1 bit / chunk

chunk_index:  0  1  2  3  4  5  6  7 ...
received:    [1][1][0][0][1][0][0][0] ...

  ├─ all_received()   → 所有位为 1 → 可 upload_done
  ├─ first_missing()  → 返回第一个 0（next_chunk_index）
  └─ 持久化：bitmap → hex → file_transfer.received_bitmap（VARBINARY）
```

### 5.5 watchdog 清理

```
每 60s 一轮
   │
   ├─ 1. 超时会话清理
   │     get_stale_transfers(timeout)
   │       → 删 tmp/<...>.part → status = failed
   │
   └─ 2. 孤儿回收（每 10 轮约 10 分钟一次）
         list_stored_files()
           → file_exists(storage_key) == false → 删磁盘文件
```

## 6. 关键调用链（速查）

```
上传：  client_session → File_handler → FileService::upload_init/chunk/done
下载：  client_session → File_handler → FileService::download_init/chunk
断线续：client_session → File_handler → FileService::upload_resume
清理：  main → FileTransferWatchdog::start → loop
广播：  handler → NoticeService::send_to_users_with_id → client_session::package_chat_message
发送：  client_session::send_file_packet → IClientTransport::send_packet(env, file_data)
```
